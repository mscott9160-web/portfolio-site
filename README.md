# Portfolio Site

Personal portfolio for Myles B. Scott - a backend engineer working on financial systems and applied AI.

**Live:** [myles-scott-portfolio.vercel.app](https://myles-scott-portfolio.vercel.app)

## What this is

A single-page site presenting my work: the platform engineering I do at USAA, the personal projects in this account, and how to get in touch. Built to be fast, readable, and simple to maintain rather than to show off framework tricks.

## Stack

- Next.js (App Router) with TypeScript
- Tailwind CSS
- Deployed on Vercel

## Running locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Structure

```
app/          Routes and page composition
components/   Shared UI components
public/       Static assets
```
